# Week 6: Prompt Engineering

Zero-shot prompts give only instructions; few-shot prompts add worked examples. Good prompts state the task, the audience, the format of the answer and any constraints.

Chain-of-thought prompting asks the model to reason step by step before answering. Use delimiters to separate instructions from data. Request structured output such as JSON when another program will read it. Watch for prompt injection, where text inside the data tries to override your instructions.
